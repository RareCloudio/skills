# Security policy

## Reporting a vulnerability

Report privately through GitHub private vulnerability reporting: open the repository's "Security" tab and choose "Report a vulnerability". Please do not open a public issue for a vulnerability.

We acknowledge reports and keep you informed until the fix ships.

## Rule for skills

Skills must never ask for a token or password in chat. Credentials are entered by the user in their own environment or the provider's own interface, never typed into the conversation. A skill that asks for one is a vulnerability: report it.
