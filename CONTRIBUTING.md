# Contributing

Issues and pull requests are welcome.

## How changes arrive here

This repository is an export. The maintainers work in a separate repository, apply accepted changes there, and they arrive here with the next export. So a pull request is not merged directly: once its change is applied, it is closed with a link to the export commit that carries it.

## What a contribution looks like

- Skills follow the Agent Skills format: https://agentskills.io
- Everything is written in English.
- No secrets, tokens, passwords or internal details, in skills, examples or pull requests.

## Security

Do not report a vulnerability in an issue or a pull request. Follow the process in [SECURITY.md](SECURITY.md).
